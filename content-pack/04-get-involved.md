# Get Involved — the journey

Connect · Grow · Lead · Sent. Four steps, one page each, plus a front page that
holds them together. This is the spine of the site: the homepage points here,
every country page points here, and every call to action lands here.

Today the same four steps exist twice — once as long sections on
`/get-involved/`, once as thin standalone pages at `/connect-2/`, `/grow/`,
`/lead/`. The front page becomes a chooser; the four pages carry the content.

Each step page uses the same frame:

```
Page header  →  Step tabs  →  Figure  →  Opening  →  Action cards  →  Next step
```
